### [MEDIUM] [New Unpatched Windows 0-Day FastUnlock Lets Someone Holding a Locked PC Run Programs on It](https://thehackernews.com/2026/11/new-unpatched-windows-0-day-fastunlock.html)
**Source:** Thehackernews | 2026-11-20
**Thème:** Vulnerabilites

Une nouvelle zero-day Windows non patchée nommée FastUnlock permet à un attaquant disposant d'un accès physique à un PC verrouillé d'exécuter des programmes sans s'authentifier, bien que cela ne confère qu'un compte utilisateur limité sans droits administrateur. La technique a été divulguée par un chercheur et analysée par ThreatLocker. Malgré la contrainte d'accès physique, cette faille de contournement d'authentification sur un système d'exploitation omniprésent en entreprise mérite une attention particulière pour la protection des postes de travail.

### [HIGH] [VMware patches vCenter zero-day exploited in attacks since September](https://www.bleepingcomputer.com/news/security/vmware-patches-vcenter-zero-day-exploited-in-attacks-since-september/)
**Source:** bleepingcomputer.com | 2026-11-20
**Thème:** Vulnerabilites

Broadcom a publié des correctifs urgents pour une vulnérabilité critique de contournement d'authentification (authentication bypass) dans VMware vCenter Server, exploitée depuis septembre 2026 par des acteurs liés à la Chine dans le cadre d'attaques zero-day. Cette faille affecte une infrastructure de virtualisation critique largement déployée en entreprise et fait l'objet d'une exploitation active confirmée, rendant la mise à jour immédiate indispensable pour sécuriser les environnements virtualisés.

### [HIGH] [nginx2root (CVE-2026-123007): HTTP/2 Flaw Lets Attackers Run Code on Unpatched nginx Servers](https://www.stepsecurity.io/blog/cve-2026-123007-nginx-http2-rce)
**Source:** vulnerabilities stepsecurity.io
**Thème:** Vulnerabilites

Une vulnérabilité critique de type RCE (CVE-2026-123007) a été identifiée dans nginx via une faille du protocole HTTP/2, permettant l'exécution de code à distance sur les serveurs web non patchés. nginx étant l'un des serveurs web les plus répandus en entreprise pour héberger des applications, cette faille représente une menace majeure nécessitant un patch immédiat pour protéger les infrastructures exposées sur Internet.
