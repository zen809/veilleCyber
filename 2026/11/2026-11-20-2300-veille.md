### [HIGH] [Linux KVM Flaw CVE-2026-99312 Lets Guest VMs Access Host Memory on AMD Hosts](https://thehackernews.com/2026/11/new-linux-kvm-flaw-cve-2026-99312-lets.html)
**Source:** Thehackernews | 2026-11-20
**Thème:** Vulnerabilites

Une faille critique (CVE-2026-99312) dans l'hyperviseur KVM du noyau Linux permet à une machine virtuelle invitée de lire la mémoire de l'hôte sur les serveurs équipés de processeurs AMD avec virtualisation imbriquée activée. Des chercheurs ont démontré la lecture de 127 Go de mémoire d'un serveur cloud DigitalOcean depuis une VM, potentiellement exposant les données d'autres clients sur les infrastructures partagées. Des correctifs ont été publiés dans les noyaux corrigés.
