### [HIGH] [Researchers Demonstrate Ghostscript Sandbox-Escape RCE via Crafted File Uploads in Popular Apps](https://thehackernews.com/2026/11/researchers-demonstrate-ghostscript.html)
**Source:** Thehackernews | 2026-11-22
**Thème:** Vulnerabilites

Des chercheurs ont démontré une vulnérabilité critique d'échappement de sandbox menant à une exécution de code à distance (RCE) dans Ghostscript, un interpréteur largement utilisé sur les serveurs Linux pour traiter les PDF et images uploadés. Cette faille, désormais corrigée, permettait à un fichier malveillant d'exécuter des commandes arbitraires sur le serveur, soulignant les risques dans les chaînes de traitement documentaire courantes en entreprise, y compris dans le secteur de la santé.
