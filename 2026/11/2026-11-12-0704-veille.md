### [HIGH] [Critical Apache HTTP/2 Flaw Could Let Unauthenticated Attackers Execute Code Remotely](https://thehackernews.com/2026/11/critical-apache-http2-flaw-could-let.html)
**Source:** Thehackernews | 2026-11-12
**Thème:** Vulnerabilites

A critical unauthenticated remote code execution vulnerability (CVE-2026-119618) has been discovered in Apache HTTP Server's mod_http2 module, affecting versions 2.4.55 through 2.4.70. The flaw allows remote attackers to execute code on servers with HTTP/2 enabled and is fixed in version 2.4.71. Organizations running affected versions should upgrade immediately to mitigate the risk.

### [MEDIUM] [ScreenConnect Attacks Target at Least 288 Endpoints Across 48 Organizations With Rogue Clients](https://thehackernews.com/2026/11/screenconnect-attacks-target-at-least.html)
**Source:** Thehackernews | 2026-11-12
**Thème:** Incidents

ConnectWise has disabled five third-party extensions in ScreenConnect partner environments following reports of unauthorized access via rogue clients targeting at least 288 endpoints across 48 organizations. The company states there is no evidence of infrastructure compromise or a vulnerability in the ScreenConnect software itself. This incident highlights ongoing attacks against remote access tools widely used in enterprise environments.

### [HIGH] [Node.js Patches 16 Security Vulnerabilities Allowing Remote Server Crashes, Memory Leaks, and Authentication Bypass](https://gbhackers.com/node-js-patches-16-security-vulnerabilities/)
**Source:** vuln gbhackers.com | 2026-11-12
**Thème:** Vulnerabilites

The Node.js Project has released security updates addressing 16 vulnerabilities across versions 22.x, 24.x, and 26.x, including 7 high-severity flaws enabling remote server crashes, memory leaks, and authentication bypass. Many vulnerabilities can be triggered remotely by unauthenticated clients through HTTP/2 and TLS handling. Patched versions v22.23.5, v24.22.3, and v26.13.1 are now available and should be deployed immediately.
