### Bulletin d'actualité CERTFR-2026-ACT-041
**Source:** ANSSI Avis | **Score:** HIGH
[lien](https://www.cert.ssi.gouv.fr/actualite/CERTFR-2026-ACT-041/)

**Vulnerabilites (CVE critiques, zero-days, patches urgents, attaque supply chain)**
- Plusieurs vulnérabilités critiques (CVSS ≥ 9.8) permettent l'exécution de code arbitraire à distance (RCE) dans des produits largement utilisés en entreprise : Check Point (CVE-2026-93616, CVE-2026-91843), F5 Big-IP (CVE-2026-94127), WordPress (CVE-2026-87902), GitLab (CVE-2026-89078, CVE-2026-93577), SolarWinds (CVE-2026-28324), et Citrix (CVE-2026-88771).
- Exploitation active confirmée pour les vulnérabilités Check Point, F5 Big-IP, WordPress, Citrix, et Arista Velocloud Orchestrator, nécessitant une application immédiate des correctifs.
- GitLab présente deux vulnérabilités critiques (CVSS 9.9) non encore exploitées mais à corriger d'urgence (CVE-2026-89078, CVE-2026-93577).
- WordPress corrige une vulnérabilité 'Click2Shell' (RCE via formulaire) dans sa version 7.1.1, mais une seconde vulnérabilité critique (CVE-2026-87902) persiste jusqu'à la version 7.1.2.
- Apache Tomcat présente des vulnérabilités critiques (CVE-2026-86248, CVE-2026-76183, CVE-2026-86350) permettant un contournement de politique de sécurité, affectant les versions 9.x, 10.x et 11.x.
- WSO2 Traffic Manager et autres produits API (CVE-2026-5430, CVSS 10) sont activement exploités pour contourner des politiques de sécurité.
