**Vulnerabilites (CVE critiques, zero-days, patches urgents, attaque supply chain)**
- WordPress a publié un correctif pour la vulnérabilité critique CVE-2026-64638 (CVSS 8.9), permettant une exécution de code arbitraire à distance (RCE) via une injection XSS si un administrateur clique sur un lien malveillant. Un exploit public est disponible.
- Cisco UCS et NFVIS sont affectés par CVE-2026-20200 (CVSS 8.8), une vulnérabilité d'élévation de privilèges avec un exploit public disponible.
- Tenable Security Center présente trois vulnérabilités critiques (CVE-2026-64877, CVE-2026-64878, CVE-2026-64879, CVSS 9.4) permettant une injection SQL et une exécution de code arbitraire à distance (RCE).
- Check Point Multi-Domain Security Management est vulnérable à CVE-2026-18574 (CVSS 9.3), permettant une exécution de code arbitraire à distance et un contournement de la politique de sécurité.
- Metabase est affecté par une vulnérabilité critique d'injection SQL (CVSS 10) activement exploitée.
- IBM Langflow OSS (CVE-2026-9198, CVSS 9.8) et JetBrains TeamCity (CVE-2026-63077, CVSS 9.8) présentent des vulnérabilités RCE activement exploitées.
- N-able N-central est affecté par deux vulnérabilités (CVE-2026-18577 et CVE-2026-18556, CVSS 8.2) de contournement de politique de sécurité, activement exploitées.
- Une campagne de compromission de paquets npm vise à voler des identifiants de développeurs et à se propager, avec des indicateurs de compromission publiés par Microsoft et Aikido.
