### [HIGH] [Critical Rails Flaw Lets Unauthenticated Attackers Read Server Files and Execute Code](https://gbhackers.com/critical-rails-flaw/)
**Source:** vuln gbhackers.com | 2026-07-30
**Thème:** Vulnerabilites

Une vulnérabilité critique (CVE-2026-66066) dans Ruby on Rails Active Storage permet à des attaquants non authentifiés de lire des fichiers arbitraires sur le serveur, avec un risque d'escalade vers une exécution de code à distance. Cette faille affecte les applications utilisant libvips pour le traitement d'images.
