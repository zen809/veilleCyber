### [HIGH] [Microsoft Fixes Azure API Management Classic Flaw as Actor Targets Customer Secrets](https://thehackernews.com/2026/11/microsoft-fixes-azure-api-management.html)
**Source:** Thehackernews | 2026-11-24
**Thème:** Vulnerabilites

Microsoft a corrigé une vulnérabilité critique dans Azure API Management Classic faisant l'objet d'une exploitation active par un acteur inconnu. Celui-ci ciblait les tokens d'accès, secrets et valeurs nommées de plusieurs entreprises norvégiennes, notamment dans le secteur énergétique, selon l'autorité de sécurité nationale (NSM).

### [MEDIUM] [WHMCS SQL Injection Could Expose Customer Data and Admin Password Hashes without Login](https://thehackernews.com/2026/11/whmcs-sql-injection-flaw-could-expose.html)
**Source:** Thehackernews | 2026-11-24
**Thème:** Vulnerabilites

Une injection SQL critique dans WHMCS, plateforme de facturation et d'automatisation utilisée par de nombreux hébergeurs, permet d'extraire sans authentification les données clients et les hachages de mots de passe administrateurs. La faille, divulguée avec deux autres vulnérabilités, expose les bases de données des installations concernées à tout internaute.

### [HIGH] [Hackers Exploit N-able MailAssure Flaw While AI Agents Exploit MONAI Label Zero-Day](https://thehackernews.com/2026/11/hackers-exploit-n-able-mailassure-flaw.html)
**Source:** Thehackernews | 2026-11-24
**Thème:** Vulnerabilites

La CISA a ajouté deux vulnérabilités à son catalogue KEV en raison d'une exploitation active confirmée : une faille SSRF (CVSS 9.3) dans N-able MailAssure et un zero-day dans MONAI Label. Ce dernier, framework d'IA dédié à l'imagerie médicale, est exploité par des agents IA, ce qui présente un risque particulier pour le secteur de la santé.
